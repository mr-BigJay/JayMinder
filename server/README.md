# اتصال OpenAI برای JayMinder 1.8.0

این سرویس مخصوص استفاده شخصی با یک توکن اتصال است؛ برای انتشار عمومی باید حساب کاربری و سهمیه مجزا اضافه شود.
کلید OpenAI فقط روی سرور است. حالت OpenAI فایل صوتی اصلی را ارسال می‌کند؛ حالت Offline و اصلاح متن Arvan جداگانه باقی مانده‌اند.

## راه‌اندازی روی سرور دارای Docker Compose

```bash
git clone --branch feat/openai-voice-transcription https://github.com/mr-BigJay/JayMinder.git
cd JayMinder/server
umask 077
cp .env.example .env
python3 -c 'import secrets; print(secrets.token_urlsafe(48))'
nano .env
docker compose up -d --build
curl --fail http://127.0.0.1:8092/health
```

در `.env` مقدار `OPENAI_API_KEY` را با کلید حساب API خود و `JAYMINDER_APP_TOKEN` را با رشته تصادفی تولیدشده تنظیم کنید. این دو کلید متفاوت‌اند. کلیدها را در Git یا چت قرار ندهید.
مدل پیش‌فرض `gpt-transcribe` طبق راهنمای رسمی فایل‌های صوتی انتخاب شده؛ دسترسی مدل باید با حساب API شما آزمایش شود. نام مدل از محیط قابل تغییر است.

نمونه Caddy روی همان سرور (دامنه واقعی خود را جایگزین کنید):

```caddyfile
voice.example.com {
    request_body {
        max_size 24MB
    }
    reverse_proxy 127.0.0.1:8092
}
```

اگر Caddy داخل کانتینر است، آدرس localhost به همان کانتینر اشاره می‌کند؛ دو سرویس را در شبکه مشترک قرار دهید و به `api:8000` پروکسی کنید. پورت ۸۰۰۰ را عمومی نکنید. این سرویس خود TLS ارائه نمی‌کند.

در اپ: ویرایش یادداشت → «OpenAI · تبدیل مستقیم صدا» → آدرس `https://voice.example.com/v1/transcribe` و **توکن اتصال سرور** → ذخیره اتصال.
انتخاب این حالت اجازه ارسال ویس را می‌دهد. توکن با Android Keystore رمز می‌شود و در `noBackupFilesDir` می‌ماند؛ بعد از نصب مجدد یا بازیابی باید دوباره تنظیم شود.

## رفتار و محدودیت‌ها

- ویس‌های جدید اپ WAV، PCM16، تک‌کاناله و ۱۶ کیلوهرتز هستند؛ حداکثر هر درخواست ۱۰ دقیقه و ۲۴ MiB است. فایل‌های قدیمی غیر WAV ممکن است فقط با موتور آفلاین قابل تبدیل باشند.
- متن زنده حین ضبط همچنان Vosk است؛ پس از توقف، فایل کامل برای OpenAI ارسال می‌شود.
- خطای اتصال، محدودیت مصرف یا پاسخ خالی باعث حذف صوت نمی‌شود؛ متن آفلاین در صورت دسترس‌بودن حفظ می‌شود. اگر بازتولید متن شکست بخورد، متن قبلی جایگزینِ خالی نمی‌شود.
- صرف بازکردن یادداشت درخواستی ارسال نمی‌کند. ذخیره متن در Room است. سرور هم نتیجه همان فایل و مدل را تا ۳۰ روز کش می‌کند (حذف هنگام درخواست بعدی) تا تلاش مجدد هزینه تکراری نداشته باشد.
- صوت فقط در حافظه موقت سرور پردازش می‌شود؛ متن کش در volume پایدار SQLite قرار می‌گیرد. برای پاک‌سازی کامل داده سرور، پس از آگاهی از حذف کش، `docker compose down -v` اجرا کنید. این فرمان یادداشت‌های گوشی را حذف نمی‌کند.
- پیش‌فرض سقف ۶۰ درخواست جدید در روز UTC است؛ تلاش ناموفق هم شمارش می‌شود. این سقف تعداد است، نه سقف دلاری؛ در حساب OpenAI هم بودجه تنظیم کنید.
- فقط **یک worker و یک replica** اجرا کنید؛ قفل جلوگیری از درخواست تکراری داخل همان پردازش است.
- این تغییر خلاصه‌سازی، دسته‌بندی یا ساخت یادآوری هوشمند را اضافه نمی‌کند؛ تمرکز نسخه اول تبدیل مستقیم صدا است.

## بررسی

```bash
python -m pip install -r server/requirements.txt pytest
python -m pytest server/tests -q
./gradlew :app:testDebugUnitTest :app:assembleDebug
```

دستور Gradle از ریشه مخزن اجرا می‌شود. گردش‌کار GitHub Actions نیز تست‌ها و ساخت APK **debug** را انجام می‌دهد؛ فایل debug ممکن است روی نسخه release قبلی نصب نشود. برای حفظ داده، نسخه نصب‌شده را بدون پشتیبان حذف نکنید.
تست‌ها از پاسخ شبیه‌سازی‌شده استفاده می‌کنند؛ تأیید کیفیت فارسی و دسترسی واقعی OpenAI نیازمند کلید معتبر و ویس نمونه است.

راهنمای رسمی: https://developers.openai.com/api/docs/guides/speech-to-text
