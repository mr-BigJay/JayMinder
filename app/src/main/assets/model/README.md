# مدل تشخیص گفتار Vosk فارسی

برای استفاده از قابلیت «تبدیل به متن» آفلاین، مدل Vosk فارسی را دانلود و در این مسیر قرار دهید:

```
app/src/main/assets/model/vosk-model-small-fa-0.5/
```

## مراحل نصب

1. مدل را از آدرس زیر دانلود کنید:
   https://alphacephei.com/vosk/models/vosk-model-small-fa-0.5.zip

2. فایل zip را استخراج کنید.

3. محتویات پوشه `vosk-model-small-fa-0.5` را در مسیر بالا کپی کنید.

4. ساختار نهایی باید شبیه این باشد:

```
assets/model/vosk-model-small-fa-0.5/
├── am/
├── conf/
├── graph/
├── ivector/
└── ...
```

## نکات

- حجم مدل حدود ۴۵ مگابایت است.
- پس از نصب، اپلیکیشن کاملاً آفلاین کار می‌کند.
- بدون مدل، ضبط صدا و یادداشت متنی همچنان کار می‌کند؛ فقط تبدیل گفتار به متن غیرفعال است.
