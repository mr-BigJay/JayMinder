# مدل تشخیص گفتار Vosk فارسی

## روش ۱ — داخل اپ (پیشنهادی)

1. یادداشت جدید → **دانلود مدل تشخیص گفتار**
2. پس از نصب، تبدیل صدا به متن کاملاً **آفلاین** است

## روش ۲ — قرار دادن در assets (برای توسعه‌دهندگان)

دانلود: https://alphacephei.com/vosk/models/vosk-model-small-fa-0.5.zip

مسیر:

```
app/src/main/assets/model/vosk-model-small-fa-0.5/
```

## بهبود کیفیت

- ضبط به‌صورت **WAV 16kHz مونو** (بهینه برای Vosk)
- تشخیص **حین ضبط** (متن زنده)
- پشتیبانی فایل‌های قدیمی m4a با resample

برای دقت بالاتر می‌توانید مدل بزرگ‌تر فارسی را دستی در `files/vosk-models/` قرار دهید.
