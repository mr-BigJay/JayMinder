# JayMinder — Offline Persian Voice Journal

اپلیکیشن اندروید بومی برای یادداشت روزانه، ضبط صدا، تبدیل گفتار به متن (آفلاین) و یادآوری — با رابط کاربری فارسی و تقویم شمسی.

## ویژگی‌ها

- **کاملاً آفلاین** — بدون نیاز به اینترنت، حساب کاربری یا سرویس ابری
- **یادداشت صوتی و متنی** — ضبط صدا، ذخیره فایل صوتی و تبدیل به متن
- **تشخیص گفتار آفلاین** — با موتور Vosk و مدل فارسی
- **تقویم شمسی (جلالی)** — تمام تاریخ‌ها با منطقه زمانی `Asia/Tehran`
- **دسته‌بندی** — ایجاد، ویرایش، تغییر نام و حذف دسته‌ها
- **فیلتر و جستجو** — بر اساس روز، هفته، ماه، سال و دسته‌بندی
- **یادآوری** — اعلان‌های دقیق با `AlarmManager`
- **رابط RTL فارسی** — فونت Vazirmatn محلی

## معماری

```
presentation/   → Jetpack Compose UI + ViewModels (MVVM)
domain/         → مدل‌ها و قراردادها
data/           → Room Database + Repositories
service/        → صدا، تشخیص گفتار، یادآوری
util/           → تقویم جلالی، فرمت فارسی
```

موتور تشخیص گفتار از طریق interface `SpeechToTextEngine` پیاده‌سازی شده تا در نسخه‌های بعدی قابلیت‌های آنلاین/AI بدون بازنویسی هسته اضافه شوند.

### خطای «package conflicts with an existing package»

اگر قبلاً نسخه‌ای با **امضای دیگر** (مثلاً APKهای خیلی قدیمی یا بیلد debug خودتان) نصب کرده‌اید، اندروید اجازه نصب روی آن را نمی‌دهد:

1. **JayMinder** را از تنظیمات گوشی **حذف (Uninstall)** کنید.
2. APK جدید را از Releases نصب کنید.

از **v1.6.7** به بعد همه APKهای GitHub Releases با **یک کلید امضای ثابت** ساخته می‌شوند و می‌توانید نسخه‌های بعدی را بدون حذف، روی همین نصب به‌روز کنید.

### انتقال داده بدون از دست دادن یادداشت‌ها

اگر نسخه قبلی را از GitHub (مثلاً v1.6.4–v1.6.6) نصب کرده‌اید و نمی‌خواهید داده‌ها پاک شود:

1. فایل **`JayMinder-v*-legacy-update.apk`** را از Releases نصب کنید (روی اپ فعلی، **بدون حذف**).
2. منوی ☰ → **پشتیبان‌گیری (دانلودها)** — فایل zip در پوشه دانلودها ذخیره می‌شود.
3. اپ را **حذف** کنید.
4. **`JayMinder-v*.apk`** (نسخه اصلی) را نصب کنید.
5. منوی ☰ → **بازگردانی پشتیبان** و همان فایل zip را انتخاب کنید.

> یادداشت‌ها و داده‌ها با حذف اپ پاک می‌شوند؛ قبل از حذف حتماً پشتیبان بگیرید.

## ساختار داده

- **یادداشت‌ها** — متن، ضبط صوتی، رونوشت، دسته، تاریخ ایجاد
- **دسته‌بندی‌ها** — نام و رنگ
- **یادآوری‌ها** — عنوان، توضیحات، زمان (شمسی/تهران)

همه داده‌ها در Room SQLite و فایل‌های صوتی در `files/recordings/` ذخیره می‌شوند.

## بهبود متن با ArvanCloud AI (اختیاری)

جریان **Offline**: Vosk → ذخیره در Room.

جریان **AI**: Vosk (متن خام) → ArvanCloud GPT (اصلاح فارسی) → ذخیره در Room. در صورت خطا یا نبود اینترنت، **متن Vosk حفظ می‌شود**.

| تنظیم | محل |
|--------|-----|
| `ARVAN_MODEL` | `gradle.properties` یا env هنگام build — **شناسه واقعی** از `GET /v1/models` |
| `ARVAN_BASE_URL` | پیش‌فرض `https://api.arvancloudai.ir/v1` |
| `ARVAN_API_KEY` | **فقط** env (اسکریپت probe) یا DataStore روی دستگاه — هرگز در Git/APK commit نشود |
| `ARVAN_BACKEND_CLEANUP_URL` | اختیاری — proxy آینده بدون کلید در اپ |

کشف Gateway:

```bash
export ARVAN_API_KEY='...'
export ARVAN_MODEL='...'   # بعد از GET /models
./scripts/probe_arvan_gateway.sh
```

## OpenAI: اتصال مستقیم از گوشی (1.8.1)

برای استفاده شخصی به سرور یا دامنه نیاز نیست:

1. ویرایش یادداشت → **OpenAI · تبدیل مستقیم صدا** → **اتصال مستقیم**.
2. کلید شخصی OpenAI را در فیلد `OpenAI API Key` وارد کنید.
3. مدل پیش‌فرض `gpt-transcribe` است؛ در صورت نیاز نام مدل قابل تغییر است.
4. **ذخیره اتصال مستقیم** را بزنید و یک ویس کوتاه ضبط کنید.

صدا از گوشی مستقیماً به `https://api.openai.com/v1/audio/transcriptions` ارسال می‌شود؛ پردازش روی OpenAI است، نه روی گوشی. متن پس از ذخیره یادداشت در Room می‌ماند. بازکردن یادداشت درخواست جدید ارسال نمی‌کند. زدن دوباره دکمه تبدیل در اتصال مستقیم درخواست جدید و هزینه دارد؛ کش و سقف روزانه سرور واسط در این حالت اعمال نمی‌شوند.

کلید با Android Keystore رمزگذاری و خارج از پشتیبان ذخیره می‌شود؛ در APK، Git یا لاگ قرار نمی‌گیرد. دکمه حذف اتصال برای پاک‌کردن کلید وجود دارد. کلید فقط به آدرس ثابت رسمی ارسال می‌شود و redirect دنبال نمی‌شود. تغییر حالت در تنظیمات وقتی اعمال می‌شود که اتصال جدید را ذخیره کنید؛ اتصال قبلی جایگزین می‌شود.

این حالت برای واردکردن کلید شخصی روی گوشی خودتان است؛ کلید مشترک توسعه‌دهنده را در اپ عمومی توزیع نکنید. هزینه API به حساب صاحب کلید تعلق دارد. دقت فارسی، دسترسی مدل و اتصال شبکه نیازمند آزمایش واقعی با کلید خودتان است.

حالت Offline با Vosk بدون اینترنت کار می‌کند؛ Arvan و سرور واسط اختیاری هم باقی مانده‌اند. اگر آنلاین شکست بخورد، اپ متن آفلاین را در صورت دسترس‌بودن حفظ می‌کند. فایل صوتی حذف نمی‌شود.
